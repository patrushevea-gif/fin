# Анализ закупки материалов и сырья

Инструмент планирования закупок по движению материалов и сырья из 1С Комплексной автоматизации.

## Открыть демонстрацию

После включения GitHub Pages инструмент доступен по адресу:

**https://patrushevea-gif.github.io/fin/**

Вся обработка выполняется локально в браузере: загруженные данные не отправляются на сервер.

## Быстрая проверка

1. Откройте демонстрацию.
2. Нажмите **«Демо-файл»** — сервис загрузит мини-файл на 40 строк и выполнит полный расчёт.
3. Ожидаемый результат: 9 срочных позиций, 10 заказов на неделе, 7 плановых, 12 с достаточным запасом и 2 излишка.
4. Для собственной выгрузки нажмите область **«Выбрать файл»** и укажите XLSX, CSV или TSV.

## Что входит в репозиторий

- `index.html` — готовая страница инструмента;
- `assets/` — стили, интерфейс и автономный XLSX-парсер;
- `Демо_движение_товаров_1С_мини_40_строк.xlsx` — быстрый тестовый файл;
- `Демо_движение_товаров_1С.xlsx` — расширенная демонстрационная выборка.

Демо-данные охватывают Завод 1 и Завод 2, ЛКМ-сырьё, хозяйственные материалы и позиции с признаком «Критичное сырьё».

## Локальный запуск

Из папки репозитория выполните:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`. Открытие через локальный HTTP-сервер необходимо для встроенной кнопки проверки XLSX.
